- **next/og(ImageResponse = satori + resvg)** 를 쓴다. Next.js 안에 이미 들어 있어 새 꾸러미 설치가 없고 Vercel 노드 함수에서 그대로 돈다. 크롬(플레이라이트)은 함수에 싣기엔 크고 느려서 쓰지 않았다.

- 속도: 로컬에서 64장 4초 안팎(한 장 수십 ms, 첫 장만 글꼴 읽기로 조금 더).

## 5. 견본과 달라진 것

- **꼬리표·뱃지·체크 목록**: 광고주가 주지 않은 말이라 지어내지 않는다. 꼬리표는 공정 전문 배너면 공정 이름, 올수리 배너면 "종합 인테리어"만. 뱃지("무료 방문 견적" 등)·체크 목록(300x250)은 늘 뺀다 → 300x250 은 견본보다 비어 보인다(큰 문구가 가운데쯤).
- **신뢰 블루 320x100**: 견본은 뱃지가 왼쪽 위에 떠 있고 꼬리표를 숨겼다. 뱃지가 없으니 꼬리표를 보통 자리에 둔다.
- **네온 320x100**: 견본은 뱃지 때문에 단추를 조금 내렸다. 뱃지가 없어 단추를 가운데에.
- **강조 글자**: 광고주 문구에서 자동으로 고른다 — 숫자가 든 낱말(30%·15년) → 없으면 마지막 낱말 → 광고주가 `*글자*` 로 감쌌으면 그곳.
- **로고**: 흰 둥근 받침 위에 작게(어두운 바탕에서도 보이게). 깨진 로고는 빼고 그린다.
- **전화가 없으면** 단추 글자 "자세히 보기 →".
- **드문 한글**(예: 뷁·쀍): 명조·검은고딕에 없는 글자는 고딕으로 대신 나온다(깨지지는 않음).
- 말줄임은 "…"(견본은 "...").
- 네온 글자 빛번짐(text-shadow)은 견본보다 약하게 보인다.

## 6. 끝나는 날 고정 조사

- **배너 등록·검토 승인·배너 교체 때 날짜를 다시 잡는 곳 없음.**
  - `saveBanner`(src/server/ads/store.ts:286-302): banner_path·run_status 만. 관리자 올리기(api/admin/ad-banner)·광고주 교체(api/partner/banner) 둘 다 이것.
  - `setRunStatus`(store.ts:254-269): run_status·note 만. `setPayStatus`(237-248)·`setOrderLink`(272-280)·문구 고치기(api/partner/orders/[id]/brief/route.ts:37)·반려(server/admin/advertisers.ts:312)도 날짜를 안 건드린다.
  - ad_orders 에 걸린 DB 트리거 없음(트리거는 20261003_ask.sql 뿐).
  - 자동 제작(bannerAuto.ts)도 banner_path·banner_desktop_path 만 적는다.
- **밀릴 수 있던 곳 1개 → 고침(커밋 2)**: 결제 확인이 자정을 넘겨 처리되면 시작일이 "처리한 날"이 되어 하루 이상 밀렸다. 이제 포트원 paidAt 날짜. 관리자 수동 주문(createOrder)은 그대로.
- **형아 판단 필요 1개(안 고침)**: 연장(pay.ts prepareExtend·finalize 연장 분기)은 "지금 끝나는 날 + 30일". 90일 광고를 시작하자마자 연장하면 **연장 결제일부터 끝나는 날까지 약 119일**이 된다. 결제사 90일 조건에 걸릴 수 있다. 안: "남은 기간 60일 이하일 때만 연장 가능".

## 8. 형아가 정할 것

1. **연장 90일 초과**(6절) — 연장을 "남은 60일 이하"로 막을지.
2. **환불 문구와 즉시 제작의 모순**(고치지 않음): /refund 3절 "제작에 착수한 뒤에는 환불되지 않습니다. 착수 전에는 전액 환불합니다", /sponsor "배너 제작 대행 제작비는 제작 착수 뒤에는 환불되지 않습니다". 이제 결제 순간 착수(그림 완성)라 "착수 전 전액 환불"이 생기지 않는다 = 제작비는 사실상 결제 즉시 환불 불가. 결제사·소비자 쪽에서 "환불 불가 시점이 결제 즉시"로 읽힐 수 있다. "무료 포함 + 수정비 따로" 구상과 같이 정리 필요.
3. **"수정 2회"** 를 어떻게 지킬지: 자동 배너가 붙으면 광고주 [내용 고치기]가 막힌다(배너가 생기면 고치기 불가 — 기존 규칙). 지금 고칠 길은 "배너 교체(직접 올리기)" 뿐. 수정 요청 흐름(계획안 §4)이 아직 없음.
4. **맡김 = 클래식** 으로 정했다. 다른 기본값을 원하면 `DEFAULT_AUTO_STYLE` 한 줄.
5. **"원하는 느낌" 칸**은 자동 그리기에 안 쓰인다(관리자 화면에만 보임). 둘지 뺄지.
6. **글꼴 17MB 를 저장소에 올림**. G마켓 산스는 무료 글꼴(상업 사용 가능, 글꼴 자체 판매 금지)이라 서버 안에서만 쓰는 건 괜찮다고 판단 — 형아 확인.
