# 광고주 페이지 2차 계획안 (2026-10-30 저녁)

> 형아 지적(10-30 저녁, 외출 전) 7건을 받아 다시 짠 계획. **아직 만들지 않음.** 형아 OK 뒤 착수.
> 지금 라이브: /sponsor(첫 화면 새 문구) → 가입 → `/partner/new` 4단계(자리 1개 → 지역·기간 → 배너 → 결제) → 하단 탭 4개(내 광고·노출 추이·결제 기록·내 정보).

## 0. 형아 지적 → 바뀌는 것

| # | 지적 | 바꾸는 것 |
|---|---|---|
| 1 | 가입도 전에 결제시키는 것 같다, 허들 큼 | 흐름을 **가입 → 광고주 홈 → 홈 안에서 자리 고르기**로. 가입은 사업자번호·전화·비번 3칸 |
| 2 | 자리 고르기가 글자뿐 | 자리마다 **실제 화면 사진(자리 표시) + 견본 배너 사진** 카드 |

## 1. 흐름

```
/sponsor ──[광고 시작하기]──> /partner/signup (3칸 + 사업자 [확인]) ──> /partner (광고주 홈)
                                                                        ├─ 자리 고르기 ──> 합계 ──> 배너(직접/제작) ──> 결제 1회
                                                                        ├─ 내 광고
                                                                        ├─ 내 배너(시안·수정 요청)
                                                                        ├─ 노출 추이
                                                                        ├─ 결제·영수증
                                                                        └─ 내 정보
```
- /sponsor의 [광고 신청] 단추 문구 → **[무료로 시작하기]**(첫 3곳 남았을 때) / [시작하기]. 가입만으로 돈 안 나감을 단추가 말함.
- 가입 직후 광고주 홈은 **빈 상태 화면**: "아직 광고가 없어요" + 자리 사진 카드 3장 미리 보임 + [자리 고르기].

## 2. 광고주 홈(요약 화면) 구성

설명문 없이 숫자·카드만.
- 맨 위: 업체명 · 사업자 확인됨 표식 · 지역.
- 카드 3개 가로: **진행 중 광고 N** · **이번 주 노출 N / 전화·클릭 N** · **다음 결제일**.
- 그 아래: 내 광고 목록(자리 사진 썸네일 + 지역 + 남은 날 + 상태 칩: 시안 준비 중 / 확인 필요 / 게재 중 / 끝남).
- "확인 필요"(시안 도착) 광고는 맨 위에 올리고 칩을 강조색으로.

## 3. 자리 고르기

- 자리 카드 6종(맨 위 띠·견적 결과 옆·공정 전문·올수리·맨 아래 띠·견적서 추천 줄). 카드 = **실제 화면 캡처에 그 자리를 색으로 표시한 사진**(지금 MarkedShots 재사용) + 견본 배너 1장 + 이름 + 가격.
- 체크박스식 **여러 개 선택**. 공정 전문은 공정도 같이 고름(도배·타일·…).
- 지역·기간은 한 번만 고르고 전 자리에 적용(자리별로 다르게 하고 싶으면 "따로 설정" 접기).
- 화면 아래 고정 **합계 띠**: "맨 위 띠 + 올수리 · 부산 · 90일 = 126,000원 (10% 할인 적용)" / 첫 달 무료면 "첫 달 0원 · 다음 달부터 N원". 고를 때마다 즉시.
- 남은 자리 0이면 카드에 "마감 · 대기 등록" (대기 명단 = 2차).
- DB: `ad_orders`에 `group_id`(uuid) 추가. 한 결제 = 한 group. 결제 금액은 group 합계. 기존 주문은 group_id = 자기 id.

## 4. 내 배너

상태 흐름(주문마다):
```
제작 요청 ─> 시안 도착(관리자 업로드 v1) ─> 광고주 확인 ─┬─ [이대로 게재] ─> 검토 ─> 게재
                                                        └─ [수정 요청](글) ─> v2 ─> 확인 ─┬─ 게재
                                                                                           └─ [수정 요청] ─> v3 ─> 확인 ─> 게재 (2회 끝, 그 뒤는 직접 올리기만)
직접 올림 ─> 검토 ─> 게재 (교체는 언제든, 교체하면 다시 검토)
```
- 화면: 시안 사진 크게(휴대폰·PC 두 크기 미리 보기) · 버전 꼬리표(v1/v2/v3) · "남은 수정 2회" · [이대로 게재] 큰 단추 · [수정 요청] → 글 칸 하나("바꾸고 싶은 점을 적어 주세요", 300자) → 보냄.
- 수정 요청 오면 관리자 쪽 `/admin/ads`에 "수정 요청 N건" 칩 + 글 보임 + 새 버전 업로드 칸. 텔레그램 알림.
- 시안 도착·게재 시작은 광고주에게 메일(Resend) + 홈 "확인 필요" 칩.
- DB: 새 표 `ad_creatives(id, order_id, version, image_path, note(광고주 수정 글), uploaded_by admin|partner, status proposed|approved|rejected, created_at)` + `ad_orders.revisions_left int default 2`. 승인된 버전이 `banner_path`로 복사됨.
- 약관 §시안: "제작 대행 시안은 2회까지 수정 요청 가능, 3번째부터는 직접 제작본 업로드" 한 줄 추가(시행일 갱신).

## 5. 노출 추이 목업(/sponsor)

- 전화 목업 안 그래프·표에 **예시 숫자**(14일 막대 30~80대, 노출 612 · 클릭 23 · 3.8%). 목업 모서리에 작게 "예시 화면".
- 사실 원칙 때문에 "실제 광고주 성과"처럼 보이는 문구는 안 씀. 진짜 성과 한 줄은 첫 광고주 3곳 한 달 뒤에 실제 숫자로.

## 6. 화면 틀

- PC(≥1024): 왼쪽 220px 메뉴(홈·자리 고르기·내 광고·내 배너·노출 추이·결제·내 정보·로그아웃), 오른쪽 본문 최대 880px.
- 휴대폰: 맨 위 제목줄(업체명 + 메뉴 단추) → 전체 화면 메뉴. 하단 탭 없음.
- 색·글꼴은 디자인 통일 규칙(2026-09-15) 그대로. 설명문은 빈 상태 화면 한 줄만.
