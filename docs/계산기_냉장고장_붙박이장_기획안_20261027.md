## 2. 냉장고장 가격 계산기

### 2-1. 간단 모드 (3단계)

| 단계 | 질문 문구(1줄) | 고르기 칸 | 기본값 | 안 고르면 가정 |
|---|---|---|---|---|
| 1 | 어떤 가전을 넣으세요? | 냉장고 1대 · 냉장고+김치냉장고 · 3대(냉장·김치·냉동) · 기존 장 고치기(리폼) | 냉장고+김치냉장고 | 첫 단계라 반드시 고름 |
| 2 | 옆에 더 붙일 칸이 있나요? | 없음 · 키큰장(팬트리) · 홈바(카페장) — 여러 개 가능 | 없음 | 없음 |
| 3 | 어느 정도 마감을 원하세요? | 가성비 · 중급 · 고급 | 중급 | 가성비~고급 전체 범위 |

- 1단계에서 "리폼"을 고르면 2단계가 바뀐다: **어디까지 고치세요?** = 문짝만 교체 · 칸막이 옮기기·자르기 · 틀과 문 새로(재생리폼). 3단계는 그대로.
- 간단 모드 치수는 엑셀 "간단 모드 가정 치수"(형아 입력)로 채운다. 예: 1대 = 폭 ___mm, 2대 = ___mm.
- 결과 위 조정 칩: `기존 장 철거 있음 / 없음`(기본 있음) · `키친핏(빌트인) 냉장고` · `엘리베이터 없음`.

### 2-2. 정확 모드 (4단계)

| 단계 | 질문 문구(1줄) | 입력 | 기본값 |
|---|---|---|---|
| 1 치수 | 장 들어갈 자리를 재 주세요 | 폭 mm(숫자) · 높이 mm · 깊이 mm · 넣을 가전(1대·2대·3대) · 키친핏 여부(예/아니오) | 폭 빈칸(필수) · 높이 2,300 · 깊이 700 · 2대 · 아니오 |
| 2 문 | 문은 어떤 걸로 할까요? | 문 재질: LPM · PET · 하이그로시 · 도장 / 손잡이: 일반 · 푸시(무손잡이) · J형 | PET · 일반 |
| 3 내부·추가 칸 | 안쪽과 옆 칸을 정해 주세요 | 서랍 개수(0~6) · 선반 추가 개수(0~10) · 분리수거 칸(0~2) · 상부장(냉장고 위 문 달린 칸) 예/아니오 · 간접조명 예/아니오 · 키큰장 폭 mm · 홈바 폭 mm · 로봇청소기장 예/아니오 | 0 · 0 · 0 · 예 · 아니오 · 0 · 0 · 아니오 |
| 4 현장 | 현장 조건을 알려 주세요 | 기존 장 철거 예/아니오 · 설치 층수(숫자) · 엘리베이터 있음/없음 · 콘센트 이동 개수 · 지역(수도권·광역시·그 외) | 예 · 10 · 있음 · 0 · 수도권 |

- 업체·전문가용 "한 번에 입력" 토글(기존 원칙 지킬 선 2번): 4단계를 한 화면에 펼침.
- 숫자 칸 허용 범위(제안, 형아 확인): 폭 600~6,000mm · 높이 1,800~2,800mm · 깊이 550~900mm.

### 2-3. 계산 공식 뼈대 (대괄호 = 엑셀 단가 칸, 숫자는 형아 입력)

```
자 수(본체)   J본 = 폭mm ÷ 300            (올림 / 소수 그대로 — 질문 7)
자 수(키큰장) J키 = 키큰장 폭mm ÷ 300
자 수(홈바)   J홈 = 홈바 폭mm ÷ 300
자 수(전체)   J합 = J본 + J키 + J홈

① 몸통      = J본 × [냉장고장 몸통 자당 · 등급]
            + J키 × [키큰장 자당 · 등급] + J홈 × [홈바 자당 · 등급]   (홈바를 "식"으로 받으면 식 단가)
② 크기 할증  = (높이 > [기준 높이]) ? J합 × [높이 초과 자당] : 0
            + (깊이 > [기준 깊이]) ? J합 × [깊이 초과 자당] : 0
            + (키친핏) ? [키친핏 정밀 가산 · 식] : 0
③ 문 재질    = J합 × [문 재질 가산 자당 · 재질]        (기본 재질 = 0원)
④ 손잡이     = J합 × [손잡이 가산 자당 · 종류]         (짝 단위로 받으면 문짝 수 환산 필요 — 질문 8)
⑤ 옵션       = 서랍 수 × [서랍 개당] + 선반 수 × [선반 개당] + 분리수거 칸 × [개당]
            + 상부장 ? J본 × [상부장 자당] : 0 + 조명 ? [간접조명 식] : 0
            + 로봇청소기장 ? [개당] : 0 + 키친핏 ? [설치키트 식] : 0
⑥ 리폼(리폼 선택 시 ①~⑤ 대신) = [리폼 종류별 식 단가 · 등급]
⑦ 현장       = 철거 ? [냉장고장 철거 식] + [폐기물 식] : 0
            + (엘리베이터 없음) ? (층수 − 1) × [계단 운반 층당] : 0
            + [지역 출장비 · 지역] + 콘센트 이동 수 × [콘센트 개당]
소계 = ① + ② + ③ + ④ + ⑤ (+ ⑥) + ⑦
총액 = max(소계, [냉장고장 최소 시공비])  → 부가세 포함 여부는 공통 시트 설정
```

**범위 만드는 법(제안)**
- 등급을 안 골랐으면: 가성비로 계산한 값 ~ 고급으로 계산한 값.
- 등급을 골랐으면: 총액 × (1 − [범위 아래 %]) ~ 총액 × (1 + [범위 위 %]) — 공통 시트 값.
- 폭을 안 넣었으면(간단 모드): 가정 폭 최소~최대로 두 번 계산해 넓힘.
- 만 원 단위 반올림, 하한은 최소 시공비 아래로 안 내려감.

### 2-4. 근거 줄(결과 화면 문장 틀)

- "폭 ___mm = ___자 기준 · 문 ___ · 손잡이 ___ · 철거 포함"
- "가정: 폭 ___mm(2대 기준) · 중급" (가정 있을 때만)
- "냉장고 제품값 제외 · 현장 실측 뒤 확정"

## 3. 붙박이장 가격 계산기

### 3-1. 간단 모드 (3단계)

| 단계 | 질문 문구(1줄) | 고르기 칸 | 기본값 | 안 고르면 가정 |
|---|---|---|---|---|
| 1 | 어디에 넣으세요? | 안방 · 작은방 · 드레스룸 · 아이방 (여러 곳 가능) | 안방 | 첫 단계라 반드시 고름 |
| 2 | 벽 길이는 얼마쯤 되나요? | 자 칩: 6 · 8 · 10 · 12 · 15자 · 직접(cm) | 위치별 가정(안방 12자 등) | 위치별 가정 자 수 |
| 3 | 어느 정도 마감을 원하세요? | 가성비 · 중급 · 고급 | 중급 | 가성비~고급 전체 범위 |

- 2단계 칩 옆에 한 줄: "1자 = 약 30cm".

### 3-2. 정확 모드 (4단계, 벽면 여러 개 가능)

| 단계 | 질문 문구(1줄) | 입력 | 기본값 |
|---|---|---|---|
| 1 치수 | 벽 폭과 높이를 재 주세요 | 벽면 목록(이름 · 폭 mm 또는 자 · 천장 높이 mm) · "벽 추가" 단추 | 안방 1곳 · 폭 빈칸 · 높이 2,300 |
| 2 문 | 문 여는 방식과 재질은요? | 여닫이 · 슬라이딩 / 재질: LPM · PET · 하이그로시 · 도장 / 손잡이: 일반 · 푸시 · J형 / 거울 문: 없음 · 바깥 · 안쪽(짝 수) | 여닫이 · PET · 일반 · 없음 |
| 3 내부 구성 | 안을 어떻게 나눌까요? | 구성: 행거 위주 · 고르게 · 수납 위주 / 서랍 개수 · 바지걸이 개수 · 이불장 칸 수 · 내부 조명 예/아니오 · 화장대 붙이기 예/아니오 | 행거 위주 · 0 · 0 · 0 · 아니오 · 아니오 |
| 4 현장 | 현장 조건을 알려 주세요 | 기존 장 철거 예/아니오(자 수) · 천장 막음 예/아니오 · 이전 설치(쓰던 장 옮겨 달기) 예/아니오 · 설치 층수 · 엘리베이터 · 지역 | 아니오 · 예 · 아니오 · 10 · 있음 · 수도권 |

- "행거 위주 / 고르게 / 수납 위주"는 행거·서랍·선반 비율을 3칸으로 줄인 것. "고르게 = 12자당 서랍 ___개" 같은 환산은 형아 기준(질문 B-6).

### 3-3. 계산 공식 뼈대

```
자 수 J = Σ 벽면 폭mm ÷ 300            (올림 여부 — 질문 7)
① 몸통      = J × [붙박이장 몸통 여닫이 자당 · 등급]
② 슬라이딩   = 슬라이딩 ? J × [슬라이딩 가산 자당 · 등급] : 0
③ 크기 할증  = (높이 > [기준 높이]) ? J × [높이 초과 자당] : 0
            + 천장 막음 ? 벽 폭m × [천장 막음 m당] : 0
④ 문·손잡이  = J × [문 재질 가산 자당 · 재질] + J × [손잡이 가산 자당 · 종류]
            + 바깥 거울 짝수 × [바깥 거울 짝당] + 안쪽 거울 짝수 × [안쪽 거울 짝당]
⑤ 내부       = J × [내부 구성 가산 자당 · 구성] + 서랍 × [개당] + 바지걸이 × [개당]
            + 이불장 × [칸당] + 조명 ? [조명 식] : 0 + 화장대 ? [화장대 결합 식] : 0
⑥ 현장       = 철거 ? 철거 자 수 × [붙박이장 철거 자당] + [폐기물 식] : 0
            + 이전 설치 ? J × [이전 설치 자당] : 0
            + (엘리베이터 없음) ? (층수 − 1) × [계단 운반 층당] : 0 + [지역 출장비]
소계 = ① + … + ⑥ ;  총액 = max(소계, [붙박이장 최소 시공비])
범위 = 냉장고장과 같은 규칙(등급 미선택 → 가성비~고급, 선택 → ±%)
```

## 8. 확신 없는 지점

| 항목 | 내용 |
|---|---|
| 단가 단위 | 냉장고장을 자당으로 받는지 모름. 글은 대부분 세트 총액으로 말함. 자당이 아니면 공식 ①을 "구성 세트 단가 + 폭 차이 보정"으로 바꿔야 함 |
| 등급과 문 재질 겹침 | 등급과 문 재질을 따로 고르게 하면 겹칠 수 있음(고급 = 도장 문이면 중복 가산). 질문 9 답으로 "등급 = 몸통·철물, 문은 따로"인지 정해야 함 |
| 범위 계산 | ±% 방식은 제안. 기존 계산기는 제품 단가 범위로 범위를 만들었음 |
| 간단 모드 가정 치수 | 모두 빈칸. 글에 "아파트 기본 냉장고장 폭 1,000~1,070mm", "안방 12자가 가장 흔함"이 있으나 근거 약함 |
| 블로그 숫자 충돌 | 슬라이딩 가산·철거비가 글마다 다름(1-2절) |
| 상담 단추 상호 표기 | 9/16 결정과 이번 지시가 다름(4절) |
| 리폼 포함 여부 | 리폼은 현장 상태에 따라 값이 크게 달라 계산기로 맞추기 어려울 수 있음 |
| 일정 | 기존 4종 틀 재사용 전제의 추정. 붙박이장 벽면 여러 개 입력에 도배 정확 모드 방 목록 부품을 빌려 쓸 수 있는지는 코드 확인 안 함 |
