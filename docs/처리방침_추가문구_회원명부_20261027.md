# 개인정보처리방침 추가 문구 초안 — 회원 명부(로그인 기록)

> 작성: 2026년 10월 27일 · 상태: **초안(형아 확인 전, 페이지 미반영)**
> 반영 위치: `src/app/privacy/page.tsx` 의 1·2·3번 항목 + 맨 아래 시행일

## 1. 바꾸는 이유

회원 명부 표(`members`)를 만들면서 로그인한 회원의 **로그인 기록**을 새로 보관한다.
지금 처리방침에는 "카카오 닉네임·카카오 고유 ID 수집"만 있고, 로그인 시각·횟수를 보관한다는 말이 없다.

## 2. 문구 초안

### 1번 "개인정보 수집 항목"에 한 줄 추가

> **로그인 기록(카카오·아이디 회원 공통):** 닉네임, 첫 로그인·마지막 로그인 시각, 로그인 횟수, 로그인 수단(카카오/아이디)을 보관합니다. 카카오 고유 ID는 원래 값 그대로 저장하지 않고, 되돌릴 수 없게 변환한 값으로만 보관합니다.

### 2번 "수집 목적"에 한 줄 추가

> 회원 수 집계, 부정 이용(도배·광고성 글 등) 방지를 위한 이용 제한, 회원 문의 대응

### 3번 "보유 및 이용 기간" 바꿈

> 회원 탈퇴 시 즉시 삭제됩니다. 저장된 견적 데이터도 함께 삭제됩니다.
> 단, 로그인 기록 중 회원을 알아볼 수 있는 값(닉네임·변환된 고유 ID)은 탈퇴 즉시 지우고, 누구인지 알 수 없는 "탈퇴 회원 1명"이라는 숫자 기록(가입·탈퇴 시각)만 회원 수 통계용으로 남깁니다.

### 맨 아래 시행일

> 시행일: 2026년 MM월 DD일 (개정) · 이전 시행일 2026년 4월 6일

## 3. 형아 확인할 것

1. 위 문구로 페이지(`/privacy`)를 고쳐도 되는지.
2. 시행일 — 명부 기능을 실제로 켜는 날(SQL 실행 + 배포일)로 맞출지.
3. 현재 6번 문구 "카카오 로그인 연결 해제 시 저장된 모든 데이터가 삭제됩니다" — 지금 코드에는 카카오 쪽 "연결 해제" 알림을 받아 지우는 기능이 없다(사이트 안 "회원 탈퇴" 버튼으로만 지움). 문구를 "회원 탈퇴 시"로 바꿀지 따로 정해야 한다.
4. 카카오 로그인은 동의 항목(카카오 개발자 설정)에 따라 이메일·프로필 사진이 로그인 정보에 딸려 올 수 있다. 명부·DB 에는 저장하지 않지만, 로그인 쿠키(암호화됨) 안에는 담긴다. 카카오 개발자 설정에서 닉네임 외 항목을 켜 두었는지 확인 필요.
